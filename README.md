A dependency-free Node 22 program that writes one single-line joke about office life to `/output/entry.txt` — and nothing else. The joke is a fixed string, so every run produces byte-identical output.

> I blocked two hours of focus time on my calendar; three people booked over it to ask when I'm free to focus.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
